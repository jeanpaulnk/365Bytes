# Now available: OAuth authentication for on-premises Exchange mailbox migrations to Microsoft 365

*Published 9 November 2026*

## Summary

Microsoft 365 Mailbox Replication Service now supports OAuth authentication for migrating mailboxes between on-premises Exchange environments and Microsoft 365. This provides a secure alternative to Basic authentication for tenant administrators managing onboarding and offboarding move jobs. The capability is available in worldwide multi-tenant environments for organizations running supported versions of Exchange Server.

## Key points

- MRS now supports OAuth for hybrid and non-hybrid mailbox migrations.
- Replaces the need to use Basic authentication credentials for migration endpoints.
- Available in Microsoft 365 multi-tenant environments.
- Requires Exchange Server Subscription Edition (October 2026 or newer) or Exchange Server 2019 CU15 with the latest October 2026 ESU.
- Basic authentication remains supported as an optional alternative.
