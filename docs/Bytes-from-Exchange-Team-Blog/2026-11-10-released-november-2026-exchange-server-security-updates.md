# Released: November 2026 Exchange Server Security Updates

*Published 10 November 2026*

## Summary

Microsoft has published the November 2026 Security Updates for Exchange Server Subscription Edition to resolve newly identified vulnerabilities. This release also addresses server instability issues caused by October 2026 Windows updates when applied alongside November Windows Server updates. Administrators managing hybrid environments or standalone servers must deploy these cumulative updates promptly.

## Key points

- November 2026 Security Updates are available for Exchange Server Subscription Edition (SE).
- Resolves vulnerabilities and fixes server instability introduced by previous Windows updates.
- Exchange 2016 and 2019 are out of support, receive no updates, and are considered permanently vulnerable.
- Updates are cumulative, allowing admins to install the latest SU directly.
- Applies to all Exchange servers and workstations running Exchange Management Tools.


!!! warning "Action required"
    Exchange administrators must install the November 2026 Security Updates on all Exchange Server Subscription Edition servers and management tools workstations.
