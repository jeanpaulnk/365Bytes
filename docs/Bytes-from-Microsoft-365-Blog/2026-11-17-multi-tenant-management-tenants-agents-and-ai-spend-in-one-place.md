# Multi-tenant management: Tenants, agents, and AI spend in one place

*Published 17 November 2026*

## Summary

Microsoft has introduced multi-tenant management capabilities in the Microsoft 365 admin center under 'All tenants'. This centralized approach allows administrators and partners to seamlessly switch between tenants, manage and govern AI agents at scale, enforce configuration baselines with drift remediation, and control AI spending across multiple environments.

## Key points

- Tenant switching is now generally available, enabling administrators to move between authorized tenants without signing out.
- Multi-tenant agent management in public preview allows cross-tenant inventory tracking, deployment, and governance of AI agents.
- Desired-state configuration in public preview helps establish security baselines and monitor for configuration drift across tenants.
- AI cost management in public preview provides consolidated visibility into consumption and reusable spending-policy templates.


!!! warning "Action required"
    IT administrators and managed service partners should review their tenant relationships, delegated roles in Partner Center or Microsoft Entra Tenant Governance, and licensing to start using multi-tenant management capabilities.
