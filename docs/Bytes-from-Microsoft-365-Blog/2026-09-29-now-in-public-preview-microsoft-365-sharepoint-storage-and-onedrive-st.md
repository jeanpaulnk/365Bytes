# Now in public preview: Microsoft 365 SharePoint Storage and OneDrive Storage


## Summary

Microsoft has introduced a public preview of pay-as-you-go billing for SharePoint and OneDrive storage, allowing organizations to scale capacity beyond their included subscription limits using an Azure subscription. Administrators can set user-specific storage caps for OneDrive and benefit from blended pricing when combining active storage with Microsoft 365 Archive. This model helps prevent overprovisioning and aligns costs directly with actual consumption.

## Key points

- SharePoint and OneDrive pay-as-you-go storage is now in public preview.
- Billing is tied to an Azure subscription, enabling budget alerts and monitoring.
- Administrators can configure individual user storage caps for OneDrive beyond SKU entitlements.
- Blended pricing applies when combining active storage with Microsoft 365 Archive.
- Quota notification banners are suppressed while enrolled in the pay-as-you-go SharePoint storage.
