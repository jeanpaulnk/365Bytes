# Bringing Claude models in Microsoft Copilot into the EU Data Boundary

*Published 5 November 2026*

## Summary

Microsoft is expanding its EU Data Boundary commitments to include Anthropic's Claude models within Microsoft Copilot. By the end of 2026, data processed by Claude models for customers in the EU and EFTA will remain within the designated regional boundary, aligning with existing enterprise data protection standards.

## Key points

- Claude models in Microsoft Copilot will process and store data within the EU Data Boundary by the end of 2026.
- Applies to eligible Microsoft 365 customers in the EU and EFTA with no additional purchase required.
- Customer data is not used to train generative AI foundation models.
- Claude models are disabled by default in the EU and EFTA, requiring administrators to enable them via the Microsoft 365 admin center if desired.
