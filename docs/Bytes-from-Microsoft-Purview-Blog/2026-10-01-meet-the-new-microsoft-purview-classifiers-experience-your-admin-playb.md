# Meet the New Microsoft Purview Classifiers Experience: Your Admin Playbook for Public Preview

!!! info "From the Microsoft Purview Blog"
    Based on [this article](https://techcommunity.microsoft.com/t5/microsoft-purview-blog/meet-the-new-microsoft-purview-classifiers-experience-your-admin/ba-p/4561324) by Sarahzin_Shane, published 01 October 2026.

## Summary

Microsoft has launched a public preview of the new unified Classifiers experience in Microsoft Purview, bringing multiple classification types into a single inventory dashboard. This centralized tool allows administrators to view matched-item counts, inspect dependent policies, and safely manage the data protection lifecycle without navigating separate screens.

## Key points

- Brings all supported Microsoft Purview classification types into a single management inventory.
- Provides visibility into classified-item counts and policy dependencies prior to making changes.
- Supports sensitive information types, Exact Data Match, trainable classifiers, and more.
- Accompanied by an administrator playbook offering workflows, testing guidance, and scenarios.
