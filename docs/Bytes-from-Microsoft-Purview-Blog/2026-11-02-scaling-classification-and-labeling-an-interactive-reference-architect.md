# Scaling classification and labeling: an interactive reference architecture update

!!! info "From the Microsoft Purview Blog"
    Based on [this article](https://techcommunity.microsoft.com/t5/microsoft-purview-blog/scaling-classification-and-labeling-an-interactive-reference/ba-p/4560925) by MaximeBombardier, published 02 November 2026.

## Summary

Microsoft has released an updated interactive reference architecture for Microsoft Purview classification and labeling, highlighting significant public previews that boost auto-labeling capacity and policy scope. Key improvements include a 5x increase in daily file processing capacity for SharePoint and OneDrive, larger simulation limits, and the ability to edit auto-labeling policies without re-triggering simulations. Additionally, a new self-contained interactive HTML architecture diagram is available on GitHub to help administrators map out deployment stages and licensing requirements.

## Key points

- Auto-labeling policies can now be edited without stopping enforcement or re-triggering simulation.
- SharePoint and OneDrive auto-labeling capacity increases fivefold to 500,000 files per tenant daily.
- Simulation limits expand from 4 million to 20 million items, and policy scopes now support up to 1,000 individual sites or 50,000 via adaptive scopes.
- A new interactive reference architecture HTML file is available for download on GitHub to visualize data flows, control layers, and licensing.
- SharePoint library default labels now apply to existing data at rest, not just new or edited files.
