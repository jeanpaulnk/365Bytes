# Copilot in Outlook: New agentic experiences for email and calendar

!!! info "From the Outlook Blog"
    Based on [this article](https://techcommunity.microsoft.com/t5/outlook-blog/copilot-in-outlook-new-agentic-experiences-for-email-and/ba-p/4514601) by GauravSareen, published 27 April 2026.

## Summary

Microsoft is introducing agentic capabilities for Copilot in Outlook, allowing the AI to autonomously manage inboxes, prioritize messages, handle scheduling conflicts, and optimize calendars. These new features are rolling out via the Frontier preview program starting April 27.

## Key points

- Copilot in Outlook now takes on continuous inbox management, including follow-up tracking and smart rule creation.
- New calendar management features allow Copilot to proactively resolve conflicts, respond to invites, and block focus time.
- Users can leverage AI to audit schedules, decline unnecessary meetings, and generate automated agendas.
- Features become available starting April 27 through the Frontier preview program for Outlook endpoints, Windows, and web.


!!! warning "Action required"
    Administrators and users interested in early evaluation can join the Frontier program to access the new Copilot agentic experiences starting April 27.
