# How Outlook Search is changing: ranking, resilience, and the feedback loop

*Published 3 November 2026*

## Summary

Microsoft is rolling out several updates to Outlook search across platforms to improve relevance, speed, and reliability. Key changes include expanding the top relevance-ranked results from three to seven, migrating more queries to a cloud-first search model with automatic local fallback, and adding calendar search spotlights. Additionally, performance optimizations have significantly reduced latency for slow queries, and a new feedback mechanism lets users rate search results.

## Key points

- Expanded the top relevance-ranked results from three to seven items across multiple Outlook clients.
- Introduced cloud-first search with automatic fallback to the local index for classic Outlook.
- Improved latency for the slowest 5% of commercial searches through authentication path optimization and cloud migration.
- Added calendar search spotlight to display matching events directly within the calendar view.
- Integrated a thumbs-up and thumbs-down feedback prompt on search results to better capture user intent.
