# Proofpoint’s Core Email Protection API solution joins the Microsoft Defender ICES vendor ecosystem


## Summary

Proofpoint's Core Email Protection API is now part of the Microsoft Defender ICES vendor ecosystem. This integration allows joint customers to view Proofpoint verdicts, manage unified quarantines, and investigate threats within the Microsoft Defender portal and Threat Explorer.

## Key points

- Proofpoint Core Email Protection API joins the Microsoft Defender ICES ecosystem.
- Enables unified quarantine management across both Microsoft and Proofpoint.
- Brings third-party detections into Threat Explorer and Advanced Hunting.
- Reduces SOC friction and context switching for organizations using both platforms.
