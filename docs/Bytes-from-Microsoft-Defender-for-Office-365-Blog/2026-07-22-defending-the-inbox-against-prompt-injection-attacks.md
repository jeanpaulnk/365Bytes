# Defending the Inbox Against Prompt Injection Attacks

*Published 22 July 2026*

## Summary

Microsoft has introduced a new capability in Defender for Office 365 to protect against indirect prompt injection attacks hidden within incoming emails. The feature automatically intercepts and quarantines malicious AI instructions before they reach user mailboxes or are processed by copilots and autonomous agents. This protection is enabled by default for eligible customers and integrates directly into existing security workflows like Explorer and Quarantine.

## Key points

- Defender now detects and quarantines malicious AI instructions embedded in emails before delivery.
- Mitigates indirect prompt injection risks targeting Copilot and Microsoft 365 agents grounded in Exchange data.
- Protection is enabled automatically by default for eligible customers with no admin configuration required.
- Detections appear under High Confidence Phish verdicts with a specific Prompt Injection Protection technology value.
- Security teams can investigate these threats using familiar surfaces like Email Quarantine, Explorer, and entity pages.
