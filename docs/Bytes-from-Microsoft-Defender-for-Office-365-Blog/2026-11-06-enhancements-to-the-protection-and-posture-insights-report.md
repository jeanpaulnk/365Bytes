# Enhancements to the Protection and Posture Insights report

*Published 6 November 2026*

## Summary

Microsoft has rolled out updates to the Protection and Posture Insights report in Defender for Office 365, adding visibility into malicious URL clicks across Teams, Office apps, and Copilot. The update also introduces insights to track filtering overrides and expands Advanced Hunting integration for deeper threat analysis.

## Key points

- New URL Protection insight tracks malicious click blocks across email, Teams, Office files, and Copilot.
- New Filtering Overrides insight highlights how organization and user exceptions impact security posture.
- Go Hunt query integration expanded to include URL Protection, Filtering Overrides, and Detection Trends.
- Available now for Defender for Office 365 Plan 2 customers in the Microsoft Defender portal.
