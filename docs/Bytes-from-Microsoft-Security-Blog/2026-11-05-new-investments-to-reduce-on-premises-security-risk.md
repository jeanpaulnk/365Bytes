# New investments to reduce on-premises security risk

*Published 5 November 2026*

## Summary

Microsoft is launching a new on-premises security initiative to harden Exchange Server, SharePoint Server, and Skype for Business Server. The updates introduce secure-by-default configurations, automated security updates, and an upgraded Emergency Mitigation Service to reduce administrative overhead and improve risk posture.

## Key points

- Automatic application of security updates is planned for Q1 2027 in connected environments.
- Hardened default configurations and drift detection are coming in Q1 2027.
- Emergency Mitigation Service 2.0 will be enabled by default starting in December 2026 for Exchange and Skype for Business, and January 2027 for SharePoint.
- New guidance will be available via Secure Now and Microsoft Security Exposure Management.


!!! warning "Action required"
    Administrators of on-premises Exchange, SharePoint, and Skype for Business servers should prepare for automated updates, hardened defaults, and enabled emergency mitigations coming in late 2026 and early 2027.
