# Security for the agentic era, powered by Microsoft Perception

*Published 17 November 2026*

## Summary

Microsoft introduced Microsoft Perception, a new AI-powered security stack designed to coordinate red, blue, and green team agents for automated threat detection, investigation, and remediation. The announcement also covers the general availability of the Integrated Security Operations Center (ISOC) in Microsoft Defender and new agentic governance features across Entra and Purview.

## Key points

- Microsoft Perception is now generally available, orchestrating red, blue, and green security agents in a closed loop.
- Integrated Security Operations Center (ISOC) in Microsoft Defender is generally available for core capabilities, bringing SIEM and UEBA features together.
- New AI Readiness Initiatives and playbooks in Perception help organizations prioritize risks and shield vulnerable assets.
- Microsoft Agent 365 and Entra Suite expand discovery and governance to 60 local and cloud agent types.
