# What defenders need to know about ARTEX, the agentic AI framework threat actors abuse

*Published 25 November 2026*

## Summary

Microsoft Threat Intelligence warns that multiple threat actor groups are abusing ARTEX, an open-source AI-powered penetration testing framework, to automate reconnaissance, credential attacks, and exploitation at machine speed. Defenders must monitor behavioral patterns of rapid, automated attack chains and implement strict credential and internet-exposure controls. Enabling automatic attack disruption in Microsoft Defender XDR is recommended to isolate affected devices.

## Key points

- ARTEX is an AI-driven autonomous penetration testing framework abused by both state-sponsored and financially motivated threat actors.
- The tool automates the entire attack chain—from network and web application reconnaissance to exploitation and persistence—at machine speed.
- Detection relies primarily on behavioral anomalies, such as bursts of high-speed activity and rapid retries, rather than static signatures.
- Microsoft recommends reducing internet-facing exposure, securing secrets, and enabling automatic attack disruption in Microsoft Defender XDR.


!!! warning "Action required"
    Security administrators and defenders must review exposure, implement Microsoft Defender mitigations, and enable automatic attack disruption.
