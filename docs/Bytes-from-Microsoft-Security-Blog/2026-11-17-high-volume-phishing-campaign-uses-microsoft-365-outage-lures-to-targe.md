# High volume phishing campaign uses Microsoft 365 outage lures to target multiple industry sectors

*Published 17 November 2026*

## Summary

Microsoft Threat Intelligence detected a widespread phishing campaign using fake Microsoft 365 outage notifications to trick users into clicking malicious links. The attack creates a false sense of urgency by claiming that emails were held during a disruption and must be restored within 24 hours. Organizations should review telemetry for associated domains, identify users who clicked the links, and enforce MFA hardening.

## Key points

- Phishing emails masquerade as Microsoft 365 service-health alerts regarding fake Exchange outages.
- Messages use randomized subject lines and redirect links to non-Microsoft domains like reallifeaccounting[.]com.
- Microsoft Defender for Office 365 automatically blocks and quarantines known campaign messages.
- Administrators should search mail telemetry, check user click activity, and reset credentials if compromise is suspected.


!!! warning "Action required"
    Exchange and security administrators should audit mail logs for the campaign indicators, check for user interaction with malicious links, and investigate potentially compromised accounts.
