# Email threat landscape: Q3 2026 trends and insights

*Published 5 November 2026*

## Summary

Microsoft Threat Intelligence published its Q3 2026 review of email and collaboration threats, highlighting trends in phishing volume, spoofed domains, QR codes, and CAPTCHA-gated attacks. The report notes that credential theft remains the primary objective, with attackers increasingly leveraging SVG files, business-service domain spoofing, and subtle display name impersonation in Microsoft Teams. Additionally, it stresses the risk of overly broad security exceptions that inadvertently allow malicious messages to bypass defenses.

## Key points

- Microsoft detected roughly 7.3 billion email-based phishing threats from July through September 2026.
- Credential theft continued to be the main objective behind nearly all malicious payloads.
- QR code phishing declined significantly compared to early-year peaks, while CAPTCHA-gated attacks and malicious SVG attachments saw a resurgence.
- Overly broad tenant- and user-level security exceptions often overrode security protections for spoofed business-service domains.
- Microsoft Teams threat actors shifted away from explicit help desk display names toward ordinary personal names.
