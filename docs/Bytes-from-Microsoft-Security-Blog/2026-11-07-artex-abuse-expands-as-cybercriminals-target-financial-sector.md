# ARTEX abuse expands as cybercriminals target financial sector

*Published 7 November 2026*

## Summary

Microsoft is tracking a financially motivated threat actor, Storm-3358, using the agentic AI framework ARTEX to target financial institutions globally. The threat actor leverages ARTEX alongside automated tools to scan systems, exploit vulnerabilities, deploy remote access trojans, and exfiltrate data. Microsoft provides mitigation guidance, Defender detections, and advanced hunting queries to help organizations defend against these AI-accelerated attacks.

## Key points

- Threat actor Storm-3358 is using the ARTEX agentic AI framework to target financial organizations.
- Attacks involve rapid vulnerability scanning, web application exploitation, credential theft, and RAT deployment.
- Microsoft has released specific behavioral signals, Defender detections, and hunting queries to identify ARTEX activity.
- Defensive strategies include utilizing honeypots, decoys, and Entra ID Protection to disrupt autonomous AI attacks.
