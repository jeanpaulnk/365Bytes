# Microsoft Entra Global Secure Access: one offering for Private Access and Internet Access

*Published 2 November 2026*

## Summary

Microsoft has introduced a single purchasing offering combining Microsoft Entra Private Access and Internet Access, alongside several new public preview and generally available features such as Cloud Firewall, TLS inspection enhancements, and Purview data security integration.

## Key points

- Microsoft Entra Private Access and Internet Access are now available as a single unified offering.
- New public previews include Cloud Firewall, Home Network Support, and simplified TLS inspection.
- General availability features include custom headers and Microsoft Purview data security integration at the network layer.
- Universal Continuous Access Evaluation now incorporates new device and risk signals.
