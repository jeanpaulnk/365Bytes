# Designing smarter access policies for hybrid enterprises

*Published 22 October 2026*

## Summary

This article discusses strategies for designing effective Microsoft Entra Conditional Access and Zero Trust policies in hybrid environments. It emphasizes shifting focus to identity as the perimeter, adapting controls for AI agents, tiering application sensitivity, and utilizing risk-based enforcement.

## Key points

- Treat identity as the primary perimeter instead of relying on network location or traditional VPNs.
- Manage AI agents as unique, least-privilege identities subject to the same risk evaluations as human users.
- Classify applications into sensitivity tiers to balance strict security with user productivity.
- Implement dynamic, risk-based enforcement rather than static allow-or-block rules.
- Maintain access policies as an ongoing operational discipline with regular reviews and tuning.
