# Scale access controls with Microsoft Entra Conditional Access policy plans

*Published 4 November 2026*

## Summary

Microsoft has announced the public preview of Conditional Access policy plans in Microsoft Entra, a framework designed to help administrators group related policies under single security objectives. This approach reduces policy sprawl by allowing shared conditions and exclusions to be defined once while applying granular rules underneath. The feature also includes migration tools to help administrators transition existing policies into the new plan format at their own pace.

## Key points

- Introduces Conditional Access policy plans in public preview for Microsoft Entra P1 and P2 customers.
- Groups related policies around a single security objective using shared conditions and granular rules.
- Includes a built-in migration tool to transition existing Conditional Access policies into plans.
- Extends Zero Trust governance to emerging identity types such as AI agents.
