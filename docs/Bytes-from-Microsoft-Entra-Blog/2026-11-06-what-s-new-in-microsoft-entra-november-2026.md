# What’s new in Microsoft Entra: November 2026

*Published 6 November 2026*

## Summary

The Microsoft Entra monthly update for November 2026 highlights new features reaching general availability and public preview, including passkeys as initial MFA methods, continuous access evaluation enhancements, and agent identity lifecycle management. It also notes an important upcoming deadline to switch to a custom telephony provider for SMS and voice authentication by February 2027.

## Key points

- New public previews include drift detection for access packages and automated guest/agent lifecycle policies.
- Passkeys and passwordless options can now be registered as the first MFA method.
- Universal Continuous Access Evaluation now incorporates device and user risk signals for faster reauthentication.
- Organizations must configure a custom telephony provider for SMS and voice authentication before February 1, 2027.


!!! warning "Action required"
    Microsoft Entra administrators using Microsoft-provided SMS and voice authentication must select and configure a supported third-party telephony provider before February 1, 2027.
