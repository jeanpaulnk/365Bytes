# Global Secure Access: Private Access and Internet Access in one offering

*Published 2 November 2026*

## Summary

Microsoft is now offering Microsoft Entra Private Access and Internet Access as a single unified Global Secure Access offering. The blog also details recent updates, including new public previews for Cloud Firewall and Home Network Support, and general availability of custom headers and Purview data security integration.

## Key points

- Microsoft Entra Private Access and Internet Access can now be purchased together as a single Global Secure Access offering.
- Cloud Firewall for clients and Home Network Support are now available in public preview.
- Custom headers in Internet Access and network-layer integration with Microsoft Purview are now generally available.
- Universal Continuous Access Evaluation now includes new device and risk signals.
