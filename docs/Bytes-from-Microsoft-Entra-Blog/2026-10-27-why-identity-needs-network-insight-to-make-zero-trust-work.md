# Why identity needs network insight to make Zero Trust work

*Published 27 October 2026*

## Summary

The article explains why identity verification alone is insufficient for a complete Zero Trust strategy and emphasizes the need to combine identity with network insights using Microsoft Entra and Global Secure Access. It highlights how unifying these controls helps monitor mid-session risks, cover non-federated apps, and enforce dynamic policies. Admins are encouraged to review their Conditional Access settings and extend them using Microsoft's integrated network access tools.

## Key points

- Identity alone cannot protect against mid-session risks, hijacked sessions, or unmonitored traffic to non-federated apps.
- Microsoft Entra combines identity and network signals to create a unified Zero Trust security architecture.
- Conditional Access is expanded to evaluate device compliance, location, and network context alongside user identity.
- Global Secure Access applies identity-driven controls to internet destinations and private applications.
- Continuous Access Evaluation allows real-time session revocation when risk profiles change.
