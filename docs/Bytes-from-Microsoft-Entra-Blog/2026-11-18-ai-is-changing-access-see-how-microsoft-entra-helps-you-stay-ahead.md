# AI is changing access. See how Microsoft Entra helps you stay ahead.

*Published 18 November 2026*

## Summary

Microsoft has announced a wide array of new Microsoft Entra capabilities aimed at securing AI agents and human identities alike. Key updates include identity verification for passkeys, expanded Privileged Identity Management (PIM) for AI agents, tenant governance controls, and comprehensive agent lifecycle management and risk-based conditional access.

## Key points

- Introduced high-assurance credentials in preview, combining passkeys with identity verification partners.
- Expanded Privileged Identity Management (PIM) and Conditional Access to support AI agents and automated workflows.
- Added Microsoft Entra Agent ID and discovery tools to track and govern both local agents and digital teammates.
- Rolled out Microsoft Entra Tenant Governance for cross-tenant configuration management and drift detection.
- Enabled automated lifecycle management and risk-based policies specifically tailored for AI agents.
